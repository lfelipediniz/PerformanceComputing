# High-Performance Computing Exercises

This repository presents a progressive collection of parallel computing problems that apply concepts learned in USP's [SSC0903 — High Performance Computing](https://uspdigital.usp.br/jupiterweb/obterDisciplina?sgldis=SSC0903&codcur=55090&codhab=0) course.

The exercises are organized by programming model and numbered in the suggested learning order:

- `01-openmp`: shared-memory parallelism with OpenMP
- `02-pthreads`: thread synchronization with POSIX Threads

Each C source file is a standalone exercise. Code comments are kept in Portuguese to preserve the original learning notes.
